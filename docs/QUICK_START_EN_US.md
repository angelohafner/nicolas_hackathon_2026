# ARTEMIS II: LUNAR ODYSSEY — Nicolas / Mission Director

## Open the experience

Open `ARTEMIS_II_Nicolas_Mission_Control_EN_US.html` in a current Chrome or Edge browser. No installation, sign-in, web server, or internet connection is required for the interface, rules, visuals, captions, or demonstration flow.

**Note about narration:** This app uses the browser's Web Speech API (`speechSynthesis`) and requests American English (`en-US`). Speech output depends on which voices the operating system and browser make available. Local en-US voices are preferred. If no compatible voice is present, captions and controls continue working offline. The app cannot bundle a guaranteed human-quality prerecorded voice in this version.

## Presentation plan for Nicolas

1. On **MISSION BRIEFING**, choose each of the three flight phases and read the changing explanation. Click each of the four resource rules. Use **HEAR MISSION BRIEFING** to demonstrate narration and live captions.
2. Select **START MISSION** to open the test lab. Show an example of a healthy spacecraft. Then use **INJECT CRITICAL FAULT** to demonstrate mass/power problems and explain that the physics inputs come from the other team members.
3. Select **OPEN PRE-LAUNCH CHECKLIST**. Press **RUN PRE-LAUNCH DIAGNOSTICS**. Watch all five checks change from **PENDING** to **SCANNING** to their actual status, accompanied by the Mission Control log and voice announcements.
4. Demonstrate that **LAUNCH LOCKED** cannot be clicked when a critical check fails. Return to the test lab, choose **RESTORE NOMINAL**, and run the diagnostics again.
5. Press **AUTHORIZE LAUNCH**. Mission Control announces: *"Flight Director, all stations report GO. Artemis II is cleared for launch. Initiating terminal countdown."* A spoken ten-second countdown follows, with captions and an **ABORT COUNTDOWN** option.
6. Advance through the three **DEMO FLIGHT** phases. This is an integration demonstration only; the other team members are building the eventual flight simulation.
7. Open **MISSION DEBRIEFING**. Point out the crew's safety status, scientific data, medals, and the comparison with the real NASA Artemis II mission. Select **REVIEW MISSION RESULTS**, then **REPLAY MISSION**.

## Scientific integrity

- The real Artemis II launched on **April 1, 2026** and splashed down on **April 10, 2026**, after **9 days, 1 hour, 32 minutes**. It was a **crewed lunar flyby**, not a Moon landing.
- Game mass limits, delta-v values, entry corridors, power thresholds, data volumes, points, and medals are educational approximations, **not NASA telemetry**.
- NASA uses **CML 4** for **Concept Maturity Level 4 / Point Design**. This project's "CML 4 pre-launch checklist" is an explicitly labeled educational adaptation.
