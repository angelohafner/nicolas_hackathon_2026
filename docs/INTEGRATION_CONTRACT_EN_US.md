# Nicolas's Module — Team Integration Contract (en-US)

The standalone HTML exposes `window.ArtemisNicolas` for future integration. Its display and launch checks are Nicolas's responsibility; the mission physics and 3D spacecraft are the other participants' responsibility.

## Update engineering inputs

```js
// Call this when the shared engineering model publishes a new spacecraft snapshot.
window.ArtemisNicolas.setShipSnapshot({
  totalMassKg: 21500,
  batteryChargePercent: 86,
  powerBalanceWatts: 55,
  heatShieldInstalled: true,
  heatShieldHealthPercent: 100,
  antennaActive: true,
  fuelRemainingDeltaV: 3200
});
```

This method validates numeric inputs and **invalidates previous diagnostic authorization**. Launch remains locked until the player runs a fresh five-system scan, even if the changed values are within a safe range.

## Read preliminary readiness

```js
// A preliminary state assessment does not itself authorize launch.
const readiness = window.ArtemisNicolas.getReadiness();
console.log(readiness.greens, readiness.criticalReds, readiness.approved);
```

The current educational rule is: at least **4 of 5 GREEN** results and **zero critical RED** items. For example, a failed noncritical radio check may still meet the game's threshold if the other four are green. Do not interpret this rule as a genuine NASA go/no-go decision.

## Open Nicolas's screens

```js
window.ArtemisNicolas.openBriefing();
window.ArtemisNicolas.openChecklist();
```

## Integration boundaries

- The current test lab and **DEMO FLIGHT** are stand-ins for future modules built by the other participants.
- Do not duplicate the other participants' physics, spacecraft components, flight rules, or 3D environments in Nicolas's module.
- The standalone HTML is not a production security boundary: the classroom game trusts its in-memory data and browser context. Its safety checks are user-experience logic for the educational simulation.
- The downloaded JSON report includes scores and physical values generated by the **educational game**, not actual NASA mission metrics.
